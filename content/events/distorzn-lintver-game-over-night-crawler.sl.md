## DISTORŽN

Letošnji prvi Distoržn bodo otvorili LINTVER, GAME OVER in NIGHT CRAWLER.

### Lintver

Thrash metal, Goriška Brda

Lintver je old-school thrash metal kvartet iz Goriških Brd, ki je bil ustanovljen leta 2004. Skupina ima za sabo že ogromno koncertne kilometrine, saj so stalni gostje slovenskih klubov in različnih festivalov. Lansko leto so izdali tretji studijski album "The Worst Is Yet To Come", ki ga sedaj tudi predstavljajo na koncertih.

### Game Over

Thrash metal / crossover

Game Over so se še kot najstniki zbrali leta 1988. Za vse člane je bil to prvi bend, v katerem so se šele učili vsega skupaj, in precej hitro so začeli s koncerti in snemanji. Označeni so bili kot metal/crossover bend in dosegli kar lepo stopnjo prepoznavnosti. Največji uspeh je bil nastop na Novem Rocku '89 (glavni bend Destruction), koncerte pa so imeli tudi s Sarcasm, Epidemic Zone, avstrijskimi Inferno ... 1990 izide kaseta Tilt. Kasneje istega leta se je vse zaključilo. Pozneje so v spremenjeni zasedbi izdali CD Eclectric z novimi komadi in tudi starimi, še neizdanimi posnetki. Po 30+ letih se originalni štirje spet dobijo in se vračajo na odre!

### Night Crawler

Thrash metal, Ljubljana / Škofja Loka

Night Crawler so štiričlanska thrash metal skupina, ki ji niso tuji tudi drugi žanri. Skupino je leta 2016 ustanovil Ljubljančan Klemen Gabrovšek (vokal, kitara). Od takrat so se, z izjemo Klemna, vsi člani skupine zamenjali. Zasedba, ki se vam bo predstavila, skupaj preigrava in ustvarja predvsem avtorsko glasbo od poletja 2022. Danes so njeni člani še kitarist Ruben Škodič iz Postojne ter Žiga Bizjak (bas kitara) in Maks Kovač (bobni) iz Škofje Loke.
